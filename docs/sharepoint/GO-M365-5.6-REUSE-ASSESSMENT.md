## Reuse Strategy

### Decision Framework

```
Is the component already present in the tenant?
   ├── YES → Is it fit for purpose as-is?
   │          ├── YES → REUSE (no changes)
   │          └── NO  → Can it be extended?
   │                     ├── YES → EXTEND (add to existing)
   │                     └── NO  → NEW (build from scratch)
   └── NO  → NEW
```

### Reuse Classification

| Classification | Definition | Examples |
|---|---|---|
| **REUSE** | Use existing component exactly as-is | Tenant, Environment, SharePoint site |
| **EXTEND** | Add to/modify existing component | Flow skeleton → full workflow, SP list → add columns |
| **NEW** | Build component from scratch | Email templates, solution package, connections |
| **KEEP** | Existing Power Automate action preserved | Compose action (original) |
| **REBUILD** | Existing component replaced entirely | Trigger schema (empty → defined) |
