## BLK-01 — Microsoft Approvals License Not Verified

### Details

| Property | Value |
|---|---|
| **ID** | BLK-01 |
| **Description** | The Microsoft Approvals connector license status has not been verified in the Maejo365 tenant. Without a valid license, the `Start and Wait for an Approval` action cannot execute, blocking the entire approval engine implementation. |
| **Impact** | 🔴 Critical — EPIC-03 cannot start without this. The flow would fail at runtime with an authorization error. |
| **Risk Reference** | R-12 (GO-M365-5-RISK-REGISTER.md) |
| **Evidence** | During GO-M365-3R7 live inspection, the Approvals connector was NOT explicitly verified. The flow's `connectionReferences` is `{}` — no connections attempted. |
| **Category** | Licensing |
| **Priority** | 🔴 P0 — blocking |

### Resolution

| Property | Value |
|---|---|
| **Resolution** | Log in to M365 Admin Center → Billing → Licenses → verify Approvals is included in the tenant license SKU. Alternatively, navigate to Power Automate Maker Portal → Connections → New Connection → search for "Approvals" — if it appears and allows creation, license is available. |
| **Owner** | M365 Administrator |
| **Estimated Effort** | 15 minutes |
| **Verification** | Connector visible in Maker Portal → Connections → New → "Approvals" |

### Fallback

If Approvals license is NOT available:
- Escalate to M365 procurement for license addition
- Explore alternative: HTTP connector + custom approval API (significantly increases scope)
- Potentially delay GO-M365-6 until license procured

## BLK-02 — SharePoint List Columns Not Created

### Details

| Property | Value |
|---|---|
| **ID** | BLK-02 |
| **Description** | The GO Approval Workflow SharePoint list exists but is empty and none of the 11 required custom columns (FR-4 specification) have been created. Additionally, write permissions for the flow owner have not been explicitly verified. |
| **Impact** | 🔴 Critical — EPIC-02 cannot start without this. The `Create_SP_Item` action would fail at runtime with a schema mismatch or permission error. |
| **Risk Reference** | R-13 (GO-M365-5-RISK-REGISTER.md) |
| **Evidence** | GO-M365-3R7 live inspection confirmed list exists and is empty. Column schema was not inspected during recovery. |
| **Category** | Infrastructure / Configuration |
| **Priority** | 🔴 P0 — blocking |

### Resolution

| Property | Value |
|---|---|
| **Resolution** | Navigate to `https://maejo365.sharepoint.com/sites/msteams_54adc4/Lists/GO%20Approval%20Workflow/` → Settings → List Settings → Create Column. Create all 11 columns per EPIC-02 tasks 2.2-2.12. Verify flow owner has "Add Items" permission. |
| **Owner** | SharePoint Administrator / Site Owner |
| **Estimated Effort** | 3 hours (11 columns × ~15 min each + verification) |
| **Verification** | All 11 columns visible in list settings; test item can be created manually |

### Column Creation Checklist

| # | Column Name | Type | Required | Status |
|---|---|---|---|---|
| 1 | `MetricName` | Single line of text | ✅ | ⬜ |
| 2 | `MetricValue` | Multiple lines of text | ✅ | ⬜ |
| 3 | `SubmitterEmail` | Single line of text | ✅ | ⬜ |
| 4 | `SubmitterName` | Single line of text | ✅ | ⬜ |
| 5 | `ApproverEmail` | Single line of text | ✅ | ⬜ |
| 6 | `ApproverName` | Single line of text | ✅ | ⬜ |
| 7 | `ApprovalStatus` | Choice (Approved, Rejected, TimedOut) | ✅ | ⬜ |
| 8 | `ApprovalDate` | Date and Time | ✅ | ⬜ |
| 9 | `ApproverComments` | Multiple lines of text | ❌ | ⬜ |
| 10 | `FlowRunId` | Single line of text | ✅ | ⬜ |
| 11 | `Title` | Single line of text | ✅ | ✓ Present (default) |

### Fallback

If SharePoint write permissions cannot be obtained:
- Request Site Owner grant Add Items to the flow owner account
- If list has unique permissions, ensure flow owner is added with Contribute level
- If all else fails: use a different SharePoint list or site that flow owner controls
