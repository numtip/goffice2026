## Behavior while assets are absent

- `PracticeImage.astro` renders **nothing** when the file is missing → the
  accent gradient / icon fallback stays intact; **no broken `<img>` state**.
- Hero renders with `loading="eager"` (above the fold); card thumbnails use
  `loading="lazy"`.
- `width`/`height` attributes are always emitted to prevent layout shift once
  assets arrive.
- No fake placeholder images were created.
